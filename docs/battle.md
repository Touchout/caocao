# 戰鬥系統（逆向進度）

分析對象：`Ekd5.exe`（新改曹操傳 6.6 引擎，社群稱「Star 的新引擎」，在光榮原版上大量改寫）。
工具：`tools/re/`（xref、disasm、callgraph、decomp）。反編譯結果在 VM 的 `out/decomp/`，不進 git。
位址都是 VA（image base 0x400000）。

## 共用函式

| 位址 | 意義 | 狀態 |
|---|---|---|
| 0x40D2AB | `get_stats(攻方, i, 守方, j)` → (攻方第 i 項, 守方第 j 項)。項目：0 攻擊、1 防禦、2 精神、3 爆發、4 士氣 | 已確認 |
| 0x4101D9 | `effect(單位, 特效編號, …)` → 該單位擁有此特效時回傳特效值（多半是百分比），否則 0。特效名稱見 `out/exe_tables.json` 的 `effects` | 已確認語意，內部尚未讀 |
| 0x425AD9 | `pct(p, x) = p * x / 100` | 已確認 |
| 0x47FA9E | `sat_sub(a, b) = a > b ? a - b : 0` | 已確認 |
| 0x47FA89 | 百分比加成，`(v, p, 100)` | 推測 |
| 0x412674 | 取單位的某個值（傷害公式裡當基礎值，推測是等級） | 推測 |
| 0x4287A8 | 擲亂數判定（4077 偽隨機開關會影響） | 推測 |

## 命中判定 0x43B4B6

```
rate = 物理 ? hit_rate_physical() : hit_rate_strategy()   // 0x43B623 / 0x43B730
if rate >= 100: 命中
if 變數4018 > 1:                       // MOD 的命中模式
    if rate >= 變數4018: 命中
    if rate <  變數4017: 未命中
重擲最多 2 次：
    if roll(rate): 命中
    if 變數4018 == 1 or rate < 85: 未命中
    rate -= 10
回傳值 = 結果 * 2
```

### 物理命中率 0x43B623

```
if 戰場狀態 == 2: return 100           // g_500e9a
if 守方特定狀態（0x47EF3D / 0x423FE8(2)）: return 100 或 0
(a, d) = get_stats(攻方, 爆發, 守方, 爆發)
rate = base_hit(a, d)                     // 0x43B53A
if effect(攻方, 30 攻擊絕對命中): return 100
if v = effect(攻方, 31 輔助攻擊命中): rate = rate * (100 + v) / 100   // 推測
if v = effect(守方, 32 輔助攻擊防禦): rate = sat_sub(rate, v)
return final_adjust(攻方, 守方, rate)      // 0x408EEE，尚未讀
```

### 基礎命中率 0x43B53A（跟原版曹操傳相同）

```
a = 攻方爆發, d = 守方爆發
if a >= 2d:   100
elif a >= d:  90 + (a - d) * 10 / d
elif a >= d/2: 60 + (a - d/2) * 30 / (d/2)
else:          30 + sat_sub(a, d/3) * 30 / (d/3)
```

## 物理傷害 0x43BC5A

參數：(攻方, ?, 守方, 是否反擊, 是否…)

```
if 守方不存在: 0
if 特殊情況 0x43637B: 固定值
if effect(攻方, 22 破甲攻擊) …                // 另一條路徑
(atk, def) = get_stats(攻方, 攻擊, 守方, 防禦)
if not 反擊 and not hit(): 0
dmg = level?(攻方) + 25                       // 0x412674
if atk >= def: dmg += (atk - def) / 5
else:          dmg = max(sat_sub(dmg, (def - atk) / 5), 1)
地形修正：0x413260 / 0x43F74F，差值為負時 dmg += pct(-diff * 5, dmg)
兵種相剋：p = 0x426737(…)；p != 100 時 dmg = max(pct(p, dmg), 1)
特效：34 減輕遠距損傷（守方）、25 衝鋒攻擊（攻方，乘以 g_500c48）、35 減輕物理損傷（守方）
if 反擊 and not effect(攻方, 72 強化反擊): dmg = max(dmg * 3 / 4, 1)   // 反擊傷害 75%
else: dmg += 0x478F08(攻方, dmg)               // 尚未讀
dmg = 0x412C78(攻方, 守方, dmg, …)             // 尚未讀
if not 反擊: dmg = 0x42423D(…)                 // 尚未讀
dmg = min(dmg, 守方目前 HP)
```

> 原版曹操傳的傷害是 (攻 − 防) / 2 + 等級 + 25；這個 MOD 改成 / 5，並加了大量特效。

## 能力值

`get_stats` 會經過：

- 0x414CCB：透過 0x440151 的函式指標表取出各項能力，再套兩層修正（0x428430、0x4363B0）。
- 0x423CED：逐項套用 Buff/Debuff（0x412BE6）。
- 0x416A38：異常狀態時減 20%。
- 特效 106 偷梁換柱、84 批亢搗虛也會介入。

攻擊力如何從武力、等級、兵種、武器算出來，還沒讀到。

## 移動

| 位址 | 意義 |
|---|---|
| 0x40BF0C | 兵種 → 地形表組別：兵種 ≤ 59 → 兵種 / 3；兵種 < 80 → 兵種 − 40；否則 40（無效）。執行時單位結構的兵種在 +0x2B |
| 0x41B7D2 | 地形表第 i 組的位址 = 0x4A3517 + i × 60（Data.e5 第 4 項載入後的位置） |
| 0x4060C4 | 組內移動消耗 = row[地形 + 30] |
| 0x43F7B8 | `terrain_info(地形)` → (適性 %, 消耗)，見下 |
| 0x45936D | 移動消耗：查表；255 且有特效 54 穿越移動時改成 1 |
| 0x438484 | 移動範圍（見下） |
| 0x437D59 | ZOC 判定：四鄰有敵軍就停下；有 54 穿越移動或 55 突擊移動時不受影響 |
| 0x4362E6 | 地圖矩形限制（劇本可限定只用戰場的一部分），範圍外不能走 |

`terrain_info`（0x43F7B8）：

```
group >= 40 → (0, 不能進入)
適性 = row[地形]，消耗 = row[地形 + 30]
地形 >= 30（地雷、戰壕…）時改查底下的原地形
有地形狀態覆寫（0x435BB1）時：適性取較大者；有指定消耗就用它
特效 62? 輔助地形狀態：適性至少 110            // 0x478E39，編號待確認
特效 63 惡路移動：可進入的地形消耗一律 1          // 0x478E4B
特效 54 穿越移動：不能進入 → 1；其餘消耗 − 1（最少 1）
```

移動範圍（0x438484）：

```
dist[起點] = 0，其餘 0xFF
依 dist 由小到大逐層處理：
    若該格不是起點且 ZOC（四鄰有敵軍）→ 不再往外展開
    四方向鄰格：超出地圖或矩形限制 → 跳過；已到過 → 跳過
        新花費 = dist + 消耗，超過移動力 → 跳過
        鄰格有單位：敵軍（且沒有穿越移動）→ 不能進入；友軍可以穿過
        dist[鄰格] = 新花費
可停留：dist 有值、而且格子上沒有其他單位
```

單位槽位：0–19 我軍、20–59 友軍、60–249 敵軍（共 250，見 0x416F38）。

朝向（劇本參數 2B）：0 北、1 東、2 南、3 西（由開戰配置推定：左邊的軍隊是 1、右邊是 3）。

引擎實作：`engine/core/.../battle/Movement.kt`。特效、地形狀態覆寫、矩形限制還沒接上。
